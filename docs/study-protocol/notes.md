# Teaching notes / preferences

## How Louis learns best
- Flow state is the goal. Frame every session as debugging, not absorbing. See `flow-study-protocol.html`.
- Active output required every session — recall, card, differential, taught explanation.
- Anki cloze is the retention engine. Sparing anime mnemonics (per his anki-cloze rules).
- Tools already owned: pdf2md, NotebookLM pipeline, RxTrack, anki dashboards. Route lectures
  through these, don't reinvent.

## Workflow
- Lectures are ingested to markdown and uploaded into RxTrack.
- Study a lecture → rounds of five atoms, one calibrated question per atom, stop when a round ends.
- A session is one tightly-scoped block tied to that lecture's objectives, never the whole deck.
