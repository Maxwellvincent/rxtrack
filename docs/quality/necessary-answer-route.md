# Necessary answer-route review and targeted repair feedback

November 3, 2026. Follow-up to the NB35 item that passed review despite an obvious positive-versus-negative choice shortcut.

## Changes

The existing key-hidden solve now reports a traceable answer route as well as a unique answer and source citations. Advanced items need a route category, an actual stem clue, a necessary taught relationship and an explanation of what must be inferred or calculated beyond renaming a stated finding. Declared outcome restatement, definition lookup or a choice shortcut cannot count as advanced application. A single formula calculation cannot establish third-order integration. Valid calculations and short causal/clinical applications remain eligible; honestly labeled first-order practice is not prohibited.

The shared writing/review/repair contract includes both observed and prospective restoration shortcuts. Changing “has recovered” into “what would permit recovery?” does not fix options whose sole restorative event is the key. Repairs must change the discriminator and plausible competing alternatives using source evidence, or report a shortfall. No forced vignette length, forbidden medical-word list or keyword-based diagnosis was introduced.

An explicit route defect cannot be overridden by the same review's positive approval flag. Old cached reviews without the new independent route policy/evidence need re-review for a new generated set; historical questions, answers and progress are not rewritten.

The repair path previously used only the key-aware review's issues. If an independent solver or deterministic gate rejected an otherwise approved item, the repair could receive an empty issue list. Rejections now retain their question index, and targeted repairs receive the combined gate/reviewer issues and distinct rationales. Retained items are excluded from the repair request. Diagnostics baseline version 6 exports only allowlisted route evidence and policy/contract metadata.
