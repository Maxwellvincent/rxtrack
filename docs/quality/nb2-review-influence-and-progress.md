# NB2 review influence and lecture Progress

## Background review sources

NB2 review material is indexed locally under the bridge's review library (`~/.local/share/rxtrack/review-sources/NB2`, configurable with `LLM_BRIDGE_REVIEW_LIBRARY`). Private source PDFs, text, paths, OCR outputs and question audits are not committed. The account's exact block ID must resolve to a block named NB2 before the shared question-generation boundary requests background context. A filename or neighboring block never activates it. The Mac bridge now supplies only the initial migration. Indexed text is saved in the signed-in account’s Firestore library as immutable bounded shards, followed by a manifest published only after every shard succeeds. Source retrieval then uses that account library before provider selection, without a Mac bridge call. It covers MCQs, atom/objective-only quizzes, generated exams, guided case generation, and the server recognition-bank generator used by calibration/engine practice. The shared selector is packaged with the Cloud Function and imported by the browser, so both use the same matching and exclusion rules. No source PDFs, credentials or local machine paths are copied into the account library. A new signed-in NB2 workspace automatically starts the one-time migration when its local bridge is available. Until that transfer is confirmed, account-wide availability is not established.

`build-review-library.mjs NB2 PDF...` uses PDFKit native text where healthy, otherwise built-in macOS Vision OCR. A contrast/inversion retry helps image-heavy slides. `--refresh` rebuilds an existing content-hashed source. Source pages, OCR method/confidence, unverified-key status and held/figure classifications are retained. Blank/short/failed/low-confidence pages and detected incomplete question/choice sets are held. Detected figure-dependent examples cannot enter text-only retrieval. These heuristic checks and OCR confidence are not a complete visual or medical review; undetected defects remain possible. Original question-bank import is separate and unchanged.

The provided seven reviews contain 876 pages. Their local packs, plus the earlier 780-row master-table extract, are registered as NB2-only supplementary context. The Tracts document's NB1 cover does not override the user's explicit NB2 assignment. Exact duplicate retrieved text is consolidated. Whole-page topic/objective retrieval uses heading relevance, bounded matching, a per-source cap and an objective-relative relevance floor; it does not pad a request with low-ranked matches merely to fill five slots. At most five units / 7,500 text characters are retrieved. No clinical facts or answer keys are promoted by retrieval alone.

The writer sees relevant review relationships and unkeyed worked examples alongside existing homework, ExamSoft, IMCQ and class examples. Original lecture evidence still controls independent key, objective, reasoning and ambiguity checks. The independent reviewer does not see the supplementary context. Per-question `reviewSourceReferences` record candidate prompt context, not proof of use or learning coverage. Once the library is published, provider choice does not change source retrieval. A confirmed source sync failure is surfaced rather than falsely reporting that the reviews were used. Existing cloud study-guide records retain their prior sync/error handling.

An approved three-question NB37 audit initially held all three drafts as recall. A concrete construction instruction now rejects named-lesion → listed-sign and symptom → synonym patterns for higher-order allocations. A corrected test using the lecture and narrowed matched source context accepted 2/3 as independently verified second-order questions in 116 seconds; one recall-shaped draft remained withheld. This is a small local audit with Codex, not proof of a full 20-question session, comprehensive medical correctness, or signed-in persistence.

## Progress workspace

Progress has one question total/accuracy summary, a dated daily-accuracy line with a weighted running-average switch and 80% reference, and a compact priority-first objective list. Additional objectives can be shown without nesting graphs inside disclosures. Exact save duplicates and performance-excluded questions are removed from the chart; real retakes remain. Timezone-aware daily bins use the learner's device timezone. Missing/undated/unlinked legacy history is not reconstructed from aggregate totals or plotted as zero. A single dated point is shown as a point, not an invented trend. The graph shows recorded practice accuracy, not an exam prediction or historical readiness estimate.

One combined slides-and-notes card handles review logging, optional reference attachment, recall scheduling and a single history disclosure. The duplicate slide-only panel and repeated question totals, current-level label, redundant worked/unseen bars, supporting-atom counter and nested objective-readiness panels were removed from Progress. Historical review records and scoring/scheduling rules are unchanged. Recent concepts are displayed directly with optional original-question details, rather than inside another last-practice disclosure.
